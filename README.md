# Fitness App

A modern fitness tracking application built with **Flutter**. The app is designed to help users plan their workouts, track completed exercises, monitor their progress, and create personalized workout plans.

## Features

### Weekly Workout Calendar

* Weekly calendar showing the days on which workouts were completed.
* Quick overview of workout consistency.
* Easy access to activity from individual days.

### Workout Goals

* Set a personal goal for the number of workouts to complete.
* Track the current number of completed workouts against the selected goal.
* Monitor progress towards the monthly or personal target.

### Workout History

* View recently completed exercises and workouts.
* Displays activity from the last three days.
* Previously recorded exercises can be edited.

### Statistics

The application provides statistics that allow users to track their training activity, including:

* Number of completed exercises.
* Number of completed workouts.
* Comparison between the current and previous month.
* Progress and changes in workout activity over time.

### Custom Exercises

* Create and add custom exercises to the exercise library.
* Use custom exercises when creating workout plans.
* Personalize the exercise database according to individual needs.

### Custom Workout Plans

* Create personalized workout plans.
* Add selected exercises to each plan.
* Organize workouts according to individual training preferences.

### Settings

* Configure workout goals.
* Manage application preferences.

## Technologies

The application was developed using:

* Flutter
* Dart
* Provider for state management
* Hive for local data storage
* Material Design

## Project Goals

The project was created to combine a practical fitness application with modern mobile application development using Flutter.

The main focus of the project is:

* Clean and intuitive user interface.
* Local data persistence.
* State management.
* Reusable custom widgets.
* Workout data analysis.
* Smooth navigation and animations.
* Modular and maintainable application structure.
